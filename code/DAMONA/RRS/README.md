# DAMONA RRS panels

## Inputs

- `genome.PstI.1000nt.digest.bed`: restriction fragments from the in silico PstI digestion. This file is generated beforehand with **GBSX**; the scripts in this folder read the result and do not run GBSX.
- `RRS_PstI_snp_all.bed`: WGS SNP positions within the candidate RRS fragments.
- `SNP_seq.bed`: WGS SNP positions used to find variants at or near restriction sites.
- `DAMONA132_CEPE_refined.vcf.gz` and its index: input for `run_beagle.sh`.
- `Damona132_snp_AD`: read-count input for the low-coverage simulation, generated by `../WGS/get_snp_panel_format.sh`.

## Workflow

1. **Phase the WGS genotypes:** run `run_beagle.sh`. It extracts each chromosome from `DAMONA132_CEPE_refined.vcf.gz` and runs Beagle to produce `beagle_chr*.vcf.gz`. Phasing assigns alleles to the two haplotypes of each individual. This is needed to determine which haplotype retains the reference allele at a restriction site, and therefore to model the resulting allelic dropout.
2. **Generate full-coverage RRS panels:** run `RRS_panels_generation.sh`. It uses the GBSX fragment BED, the two SNP BED files, and the phased Beagle VCFs. `RRS_panels_generation.R` accounts for restriction-site allelic dropout, filters SNPs by call rate and minor allele frequency, and writes VCF panels that the shell script converts to `RRS15K_gen.txt`, `RRS30K_gen.txt`, and `RRS50K_gen.txt`.
3. **Analyse a full-coverage panel:** run `run_zooroh_rrs.R` after selecting the desired genotype file in the script.
4. **Prepare low-coverage RRS inputs:** run `RRS_panels_generation_lowcov.sh`. It uses the same BED files and phased VCFs and writes `RRS15K_positions_to_downsample.txt`, `RRS30K_positions_to_downsample.txt`, and `reads_to_correct.txt`.
5. **Simulate low-coverage RRS:** run `makeRRSlowcov.sh`. It uses `reads_to_correct.txt`, a selected positions-to-downsample file, and `Damona132_snp_AD`. Set the desired panel/coverage parameters in `makeRRSlowcov.f90` before running.
6. **Analyse a low-coverage panel:** run `run_zooroh_rrs_lowcov.R` after selecting the generated genotype file in the script.

The order above is also listed in `order_of_steps`. The GBSX digestion output and the required SNP/read-count inputs must be prepared before running the steps that use them.
