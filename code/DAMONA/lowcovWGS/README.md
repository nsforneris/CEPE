# DAMONA low-coverage WGS

## Workflow

1. Ensure `Damona132_snp_AD` exists; it is generated by `../WGS/get_snp_panel_format.sh`.
2. For a single target coverage, configure `pcov` and `seed` in `makelowcov.f90`, then run `makelowcov.sh`. It writes `out_vcf_lcWGS_0.5x_gen.txt` with the current settings in the script/program.
3. For the combined 2x/5x/10x dataset, run `makelowcov_combined.sh` using `makelowcov_combined.f90`. It writes `out_vcf_lcWGS_2x5x10x_gen.txt`.
4. Run `run_zooroh_lcWGS.R` with the genotype filename, coverage label, and subset number as command-line arguments, e.g. `Rscript run_zooroh_lcWGS.R <genotype_file> <coverage> <subset>`.

The Fortran parameters and filenames may need to be changed for a different coverage target.
