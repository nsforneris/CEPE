# DAMONA SNP arrays

## Workflow

1. Ensure `6K_Array_gen.txt` and/or `30K_Array_gen.txt` has been generated by `../WGS/get_snp_panel_format.sh` using `6K_ids.txt` and `30K_ids.txt`.
2. Run `run_zooroh_arrays.R`. The active input is `6K_Array_gen.txt`; edit the script to select `30K_Array_gen.txt` if needed.

The script saves `zr_6K_Array.RData` (or, if changed, `zr_30K_Array.RData`).
